# Change: Add Gallery ZIP Import and Restore

## Why

Users can export Gallery as ZIP but cannot restore it back in-product. This blocks practical backup/recovery workflows.

## What Changes

- Add "Import Gallery" action in Gallery sidebar dropdown
- Support importing `.zip` packages generated by Gallery export
- Add pre-import mode selection dialog with default "Append Import" and optional "Overwrite Restore"
- Overwrite mode clears drawings, collections, and file store before importing
- Extend export metadata (`data.json`) to include optional collections and drawing-to-collection mapping for richer restore
- Keep import backward compatible with old ZIP packages that only contain `.excalidraw` files
